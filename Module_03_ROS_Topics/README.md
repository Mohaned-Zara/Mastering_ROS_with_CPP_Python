# Module 3: ROS Topics

This module covers communication between ROS nodes using topics, publishers, and subscribers in C++ and Python.

---

## 📚 Sessions

### Session 1 — Introduction

Introduction to ROS topics and asynchronous communication between nodes.

### Session 2 — Creating Your First Publisher Using C++

**Topics:**
- ROS publishers
- Topic creation
- Publishing messages
- `ros::Publisher`

### Session 3 — Creating Your First Subscriber Using C++

**Topics:**
- ROS subscribers
- Topic callbacks
- `ros::Subscriber`

### Session 4 — Creating Your Python Publisher

### Session 6 — Debugging Topics with CLI

**Topics:**
- `rostopic list`
- `rostopic echo`
- `rostopic info`
- Topic debugging

Practical experiments using Turtlesim and ROS topics.

### Session 8 — Wrap-Up

Review of ROS topic communication and publisher/subscriber patterns.
